## 二、互动 finale（s6）· 点一点那道缺口

**画面**（380×340 左右）：上 2/3 夜空，一轮大缺月特写（月牙开口朝向画面下方），缺口处有微弱 amber 呼吸光晕（opacity 动画，同 hintp/lampbreathe 手法）；下 1/3 阳台栏杆一角 + 朱迪后脑和一只竖起的大耳朵（侧影），栏杆上搁着吃剩的月牙面包。

**交互**（点三下，"风一阵一阵吹进来"）：
1. 第一下：缺口泛暖光；第一阵风——几片 cream 花瓣（HTML DOM 元素，CSS 斜向飘落+淡出，遵守"动效用 HTML/opacity"纪律）从月缺口飘向画面下方
2. 第二下：第二阵风——一缕香气细线（.steam 式 stroke 动画）+ 零星光点掠过
3. 第三下：风再来——朱迪的耳朵轻轻一歪（两只耳朵 path 用 opacity 0/1 切换实现"动"），月亮整体微微变亮、缺口透光
4. 完成：提示语换成"**风，吹进来了。**"，尾声两行按 `.lines p.on span` 模式浮现

- 提示语初态："点一点那道缺口"（amber 呼吸）
- 点空处随机计一次（先例：evidence/goodnight 的兜底逻辑）
- `?stage=final` 直达终态；`?static=1`、`&only=sN` 照常支持

## 三、音频（BGM）

- 调性：**E♭ 大调**（书房A/雨E/火车G/天气D/彩排C/晚安F/偏心B♭ 之外的新调）
- 风格：**lullaby**（低音铺底、音符依次落下，配巷子漫步感；tempo ≈4800 放慢）
- 和弦进行走出 I–vi–IV–V 家族：**Cm 开头（小调起头=硌的感觉）→ A♭ → Fm7 → B♭7（开放、待回）**，四和弦循环，具体频率开发时按 story.js 现有格式算
